# Revisiones documentales por lote

Los archivos `LOTE_01.md` a `LOTE_11.md` son notas de investigación redactadas a mano a partir de la revisión del **24 de octubre de 2026**. No existe un generador que las mantenga sincronizadas con los CSV. Cada nota conserva las fuentes, preguntas y resultados de esa revisión; sus cantidades no son un contador del estado actual.

Cuando llegue evidencia nueva, registrar primero el resultado en el CSV del lote y conservar su referencia. Si se amplía una nota, añadir la fecha y distinguir el nuevo resultado de la revisión anterior; no presentar una pregunta histórica como una decisión vigente.

Para conocer qué sigue abierto, ejecutar **Callejero: Ver pendientes** con `main` actualizado. El informe se calcula desde los lotes y las conformidades actuales; ver [cómo continuar los pendientes](../PENDIENTES.md).
