# Entrega de ejemplo · instantánea histórica

Este paquete se incorporó el **18 de septiembre de 2026**, en el commit [1d220779aa62fdaf761af2004a965a2629073332](https://github.com/los-topos-cosmicos/callejero-yacanto/commit/1d220779aa62fdaf761af2004a965a2629073332). Es un ejemplo generado del estado inicial: 241 registros sin revisar, 6 propuestas, 4 consultas y ninguna conformidad. No representa los lotes actuales.

Se conserva como material de aprendizaje; no se regenera con cada cambio de datos. `manifest.json` registra las huellas de sus insumos y salidas originales. Este README se añadió después para explicar su alcance y no forma parte del manifiesto original.

El PDF y el acta son documentos de ejemplo para revisión y cumplimentación. No acreditan firma municipal, prueba real en AutoCAD ni georreferenciación verificada.

Para obtener una entrega actual, usar **Callejero: Generar entrega** en Codespaces, o ejecutar `python3 scripts/generar_entrega.py` con las dependencias instaladas. Los paquetes nuevos se generan en `build/`, sin reemplazar esta instantánea ni una entrega anterior. Para la lista actual de trabajo, usar **Callejero: Ver pendientes**.
